# تست سرتاسری (E2E) با Playwright — کازین گالری

این پوشه (`e2e/`) یک اسکریپت واقعیِ مرورگر-محور است که مهم‌ترین جریان‌های
فروشگاه را از ابتدا تا انتها اجرا می‌کند:

1. صفحهٔ اصلی (ردیف‌های محصول + کاشی‌های برند ویژه)
2. افزودن به سبد به‌صورت **مهمان**
3. **ثبت‌نام** و ادغام سبد مهمان با حساب تازه
4. اعمال **کد تخفیف** در تسویه‌حساب (اختیاری با `E2E_COUPON`)
5. ثبت سفارش با **هر سه روش ارسال** (عادی، اکسپرس، دریافت حضوری) و پرداخت روی
   **درگاه آزمایشی (mock)**
6. بررسی اینکه سفارش‌های پرداخت‌شده در `/account/orders/` دیده می‌شوند

> این اسکریپت عمداً جزو `npm test` یا `manage.py test` **نیست**؛ چون به سرورِ
> در حال اجرا و مرورگر واقعی نیاز دارد.

## پیش‌نیازها

```bash
cd frontend
npm install
npx playwright install chromium   # فقط اولین بار — دانلود مرورگر
```

## بالا آوردن استک

ترمینال ۱ — بک‌اند (با درگاه آزمایشی و پیامک کنسولی):

```bash
cd backend
export DJANGO_SETTINGS_MODULE=config.settings.development
export PAYMENT_GATEWAY=mock SMS_ENABLED=False
export POSTGRES_HOST=... POSTGRES_USER=... POSTGRES_PASSWORD=... POSTGRES_DB=...
python manage.py migrate
python manage.py seed_demo        # کاتالوگ نمونه + برندهای ویژه
python manage.py runserver 0.0.0.0:8000
```

ترمینال ۲ — فرانت‌اند (پراکسی `/api` به بک‌اند طبق `vite.config.js`):

```bash
cd frontend
npm run dev                       # http://localhost:5173
```

## اجرا

```bash
cd e2e
E2E_BASE_URL=http://localhost:5173 npx playwright test
```

متغیرهای محیطی:

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `E2E_BASE_URL` | `http://localhost:5173` | آدرس فرانت‌اندِ در حال اجرا |
| `E2E_COUPON` | خالی | کد تخفیف فعال؛ خالی = گام کد تخفیف رد می‌شود |

کد تخفیف را می‌توانید در پنل مدیریت (بخش «تخفیف‌ها») ساخت. شماره موبایل حساب
تستی در هر اجرا تصادفی ساخته می‌شود تا اسکریپت روی دیتابیس تکرارپذیر بماند.

## وضعیت اجرا در این مخزن

این اسکریپت در محیط توسعهٔ فعلی **اجرا نشده است**، چون مرورگر سر‌خط
(Chromium/Playwright browsers) در آن محیط نصب نیست. مسیر اجرا و انتخابگرها از
روی قالب‌ها و متن‌های واقعی صفحه‌ها (ثبت‌نام، تسویه‌حساب، درگاه آزمایشی) نوشته
شده‌اند، اما اولین اجرای واقعی باید روی ماشین دارای مرورگر انجام شود و هر
انتخابگرِ شکننده احتمالی همان‌جا اصلاح گردد.
